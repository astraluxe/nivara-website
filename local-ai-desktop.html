00 What it is

Desktop software, in the way that word used to mean.

Installs locally · runs locally · stores locally

Most tools described as "AI apps" are websites. Your prompt travels to a data centre, is processed on hardware you do not control, and the result comes back. That is fine for asking about the weather and quietly unacceptable for a client's contract, an unreleased product plan or a customer list.

adris is an actual desktop application. It installs from a small package, opens without a login screen standing between you and your own files, and does its work on your processor. Conversations live in a SQLite database on your disk. Credentials live in an encrypted local store. Documents you point it at are read where they are.

02 Offline use

Works with the wifi off.

Point adris at a local model and the whole thing runs with no internet connection at all — chat, document reading, automation steps and code assistance included. That matters on a flight, on a client site with a locked-down network, or anywhere a connection is expensive and unreliable.

If you would rather use a frontier model, connect your own API key and the calls go straight from your machine to that provider. There is no middle server of ours in the path either way.

03 Requirements

What it needs from your computer.

  • Windows 10/11 or Linux. The installer is around 10 MB.
  • 8 GB RAM is enough for the app and a small local model; 16 GB is comfortable for mid-size models.
  • No GPU required. A GPU makes local models faster, it is not a condition of running them.
  • No account required to use local models — you can install and run without signing in anywhere.

05 Questions

Common questions

Is this a wrapper around ChatGPT?

No. It runs open models on your machine, and it can additionally connect to a provider using your own API key if you want one. Neither path routes through our servers.

Does it work on Mac?

Windows and Linux today. macOS is not available yet.

Where is my chat history stored?

In a SQLite database file on your own disk. It is not synced anywhere unless you explicitly turn something on.

What does it cost?

There is a free tier with all eight modules and local models. Paid plans add cloud AI credits and higher automation limits.

Is there a Mac version?

Not yet. Windows and Linux today.

How big is the download?

Around 10 MB for the app. Local models are downloaded separately and only if you want them.

Do I need to create an account?

Not to install it or to run local models. An account is needed for cloud AI credits and syncing.

What happens if I lose internet?

Local models, document reading, the editor and local automations all keep working. Steps that call an outside service wait.

Can I use my own OpenAI or Claude key?

Yes. Calls go straight from your machine to that provider, with the key stored in an encrypted local store.

Is my data used for training?

There is nothing to train on — it does not leave your machine. If you connect your own provider key, that provider’s terms apply to those calls.
